🌍 WanderLust – Travel Listing Web Application

WanderLust is a full-stack web application inspired by Airbnb that allows users to explore destinations, create listings, leave reviews, and view locations on an interactive map. The project focuses on real-world features such as authentication, authorization, CRUD operations, and responsive UI design.

🚀 Features
🔐 Authentication & Authorization

User Signup / Login / Logout

Authentication implemented using Passport.js

Secure access to routes (only logged-in users can add/edit listings or reviews)

🏠 Listings

Create, edit, and delete travel listings

Upload images for listings

View all available destinations

Filter and search destinations based on location

⭐ Reviews

Add reviews and ratings to listings

Delete reviews (only by the review author)

🗺️ Maps Integration

Interactive maps displayed for each listing

Location-based visualization for better user experience

📱 Responsive Design

Fully responsive UI for desktop and mobile devices

🛠️ Tech Stack
Frontend

EJS (Embedded JavaScript Templates)

HTML, CSS, JavaScript

Bootstrap for styling

Backend

Node.js

Express.js

MongoDB (Database)

Mongoose (ODM)

Authentication & Security

Passport.js

Express Sessions

Password hashing and secure authentication

Deployment
